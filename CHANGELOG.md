# Changelog / 更新记录

Format: [Keep a Changelog](https://keepachangelog.com/); versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] – 2026-10-19

### Added / 新增
- Seven pipelines P1–P7 by platform resolution × scRNA-seq reference availability, with config presets in `assets/configs/`.
  按平台精度 × 是否有单细胞参考划分的 7 套流程，以及对应的配置预设。
- Modules A–G (load, preprocess, annotate, domain/niche, neighbourhood, communication, special analyses) and R ↔ Python bridge scripts.
- `Z_provenance/validate_config.py` (JSON Schema validation) and `record_provenance.py` (config copy, software versions, checksums).
- `schemas/` (config JSON Schema, AnnData data contract), `envs/tested_versions.tsv`, `CITATION.cff`, `codemeta.json`, English and Chinese READMEs.
- `references/multi_sample.md`: every step classified as joint / per-sample / single-sample / requires several samples, with reasons; purpose statement in both READMEs.
- `notebooks/`: a JupyterLab notebook for every Python script, generated by `tools/make_notebooks.py` (same code, section headings and a result sentence after each cell).
- R steps rewritten as R Markdown reports (`run_rctd.Rmd`, `domain_banksy.Rmd`, `seurat_to_mtx.Rmd`) following the readable-coding report layout; pipelines render them to `results/reports/`.
- Installable in both Claude Code (`~/.claude/skills/`) and Codex (`~/.codex/skills/`): pipelines locate the skill from their own path and pass it on as `SPATIAL_SKILL_DIR`.
- Worked example (four Visium samples with a scRNA-seq reference) in `SKILL.md` and both READMEs; README prose rewritten for plainer wording.
- Released under the MIT licence. / 以 MIT 许可证发布。
- `docs/`: Figure 1 decision flowchart (data → P1–P7), Figure 2 step-by-step chart per data type, Figure 3 per-pipeline diagrams with what each step reads and writes, Figure 4 data-flow chart (SVG, English and Chinese, low-saturation BioRender-style palette: blue (Python steps), red (R steps), yellow (key output, reference available) and neutral grey) generated by `docs/make_figures.py`.
- `tests/`: simulated data in real platform formats and an end-to-end runner for all seven pipelines.

### Fixed relative to the original example scripts / 相对原始示例脚本的修正
- Coordinates converted to µm on load; all radii in µm.
- Spatial graphs built per sample; CosMx uses global coordinates.
- `sq.gr.ligrec` (no spatial information; all-NaN p-values in squidpy 1.6.5) replaced by LIANA+ bivariate / CellPhoneDB within neighbourhoods.
- Differential neighbourhood enrichment uses samples as replicates (Welch t-test) instead of subtracting co-occurrence matrices; CellCharter 0.3.5 `diff_nhood_enrichment` avoided (fails with `n_jobs=1`, hangs with process pools).
- RCTD doublet mode uses lower UMI thresholds (`UMI_min=20`, `UMI_min_sigma=100`) for HD bins.
- BANKSY λ = 0.8 for spatial domains (0.2 gives cell types).
- MISTy, neighbourhood enrichment and Moran's I now run per sample and are then summarised (mean + number of samples agreeing); pooling let cross-sample neighbours (MISTy) or between-sample differences (a batch-only gene had pooled Moran's I = 0.19 vs ≈ 0 per sample) into the results. Classification checked against how each course script handles samples.
- `niche_composition.py` also writes per-sample niche composition (`niche_composition_by_sample.csv`) for sample-level tests, as in the course's per-patient niche summary.
- Process pools that re-execute scripts under `spawn` (macOS/Windows) avoided.
- Full list: `references/script_map.md`.
